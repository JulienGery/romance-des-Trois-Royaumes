# Level5FontAtlas

Outil .NET qui lit les polices Level-5 (`.xf`) et produit l'atlas de la police française. Il est **dérivé du code de
[Kuriimu2](https://github.com/FanTranslatorsInternational/Kuriimu2)** (dossier `Level5/` : archives, compression, polices, images),
publié sous **GNU GPL v3** ; le code de ce dossier est donc distribué sous la même licence (voir `LICENSE`).
L'adaptation (programme `Program.cs`, `FrenchCharset.cs`, stubs) a été écrite avec l'aide de Claude (Anthropic) à partir de ce code.
