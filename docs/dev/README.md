# Documentation de développement

Notes de travail du projet, écrites au fil du développement (en français). À lire dans cet ordre pour comprendre le moteur :

1. [`HANDOVER.md`](HANDOVER.md) : état du projet, carte du dépôt, commandes, pièges.
2. [`JOURNAL_MODIFICATIONS.md`](JOURNAL_MODIFICATIONS.md) : spécification de chaque modification du jeu (référence du port ARM).
3. [`RAPPORT_police_variable.md`](RAPPORT_police_variable.md) : analyse du code de rendu de texte (décompilation).
4. [`PLAN_police_et_bulles.md`](PLAN_police_et_bulles.md), [`PLAN_correctifs_texte.md`](PLAN_correctifs_texte.md) : plans et résultats par phase.
5. [`annexe_appelants_texte.csv`](annexe_appelants_texte.csv) : les 130 fonctions qui dessinent du texte.

Ces documents décrivent l'historique : en cas de doute, le code fait foi. Pour l'usage courant, voir [`../TECHNIQUE.md`](../TECHNIQUE.md).
